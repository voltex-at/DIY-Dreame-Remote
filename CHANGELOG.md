# Changelog

## 0.1.0-bringup - 2026-10-15 (development)

- Independent ESP-IDF project for ES3C35P N16R8, based on the attributed Shelly board port.
- Portrait LVGL UI, touch/color tests, brightness, screen off and touch wake.
- Portable three-robot registry and command/readback guard with native tests.
- Native sanitizer CI and hardware build/package with memory reports and SHA-256.
- Compatibility research and a staged Matter/OTA implementation design.
- No Matter integration, active robot commands, Wi-Fi setup or OTA installation yet.
